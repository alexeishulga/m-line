# АРКА 123 — «Встречаемся напротив Библиотеки»

Промо-сайт пространства для мастер-классов и семинаров: 123 м², потолки 4,5 м, два арочных окна 4 × 3,5 м с видом на Национальную библиотеку.

Одностраничное приложение (SPA) на **React 19 + TypeScript + Vite**. 3D — Three.js через `@react-three/fiber`/`drei`, анимации — GSAP + ScrollTrigger, плавный скролл — Lenis.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # просмотр сборки
npm run lint       # ESLint
npm run typecheck  # TypeScript
npm run images     # пересобрать WebP из assets/ (нужен Python 3 + Pillow)
```

## Где править контент

Все тексты, цены, тарифы, отзывы и контакты лежат в одном файле: **`src/data/content.ts`**.
Цены, контакты и отзывы — **заглушки**, их нужно заменить реальными данными. Реплики Анны — в `src/components/anna/script.ts`.

Форма заявки пока открывает почтовый клиент (`mailto:`), бэкенда нет.

## Структура

```
src/
  components/logo/   логотип: точные контуры (трассировка PNG) + маски-центрлинии, прелоадер, hover
  components/anna/   персонаж: SVG по слоям, позы, сценарий, анимация
  three/             3D-зал, мебель, сценарии расстановки, маршрут камеры
  sections/          блоки страницы
  data/content.ts    контент
  store/             zustand: текущая сцена, выбранная расстановка, прогресс загрузки
scripts/optimize-images.py   PNG (44 МБ) → WebP (~4,5 МБ) в public/img/
docs/                        текстовые описания заданий
```

## Бренд

- Цвета: `#20363F` (основной, снят с логотипа), кремовый `#F4EEE5`, бумага `#FBF8F3`, дуб `#C79A62`, закат `#EF9F5A`.
- Шрифты: Manrope (заголовки, близок к вордмарку) и Inter (текст, близок к шрифту слогана); подключены локально через `@fontsource` с кириллицей.
