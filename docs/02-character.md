# Задание 2. Фирменный персонаж — Анна

## Кто она

**Анна, 32 года, управляющая пространством АРКА 123.** Она встречает гостей, знает зал до сантиметра и всегда напоминает: «Встречаемся напротив Библиотеки».

- **Внешность:** славянский тип, светло-русые волосы, гладко убранные в низкий пучок с боковым пробором, серо-голубые глаза, светлая кожа с лёгким румянцем, спокойная полуулыбка. Маленькие жемчужные серьги.
- **Одежда:** строгий приталенный костюм на одну пуговицу в фирменном тёмно-сине-бирюзовом цвете `#20363F`, брюки-сигареты, кремовая блуза, классические чёрные лодочки.
- **Брошь:** на левом лацкане — брошь в форме иконки логотипа (арка с «123»): серебряный контур и цифры на эмали фирменного цвета, как на мокапе `assets/adv/adv-material-1.png`. Время от времени по броши пробегает блик.
- **Характер:** доброжелательная, собранная, немногословная. Говорит коротко и по делу, с лёгкой гордостью за вид из окна.

## Стиль

Плоская editorial-иллюстрация в палитре бренда: тёмно-сине-бирюзовый, кремовый, тёплый оранжевый, мягкие тени без обводок. Персонаж собран в SVG по слоям, чтобы его можно было анимировать без покадровой отрисовки:

| Слой | Что анимируется |
|---|---|
| Голова | наклон, лёгкое «дыхание» |
| Глаза | моргание (случайный интервал), взгляд следит за курсором |
| Плечо → предплечье → кисть (×2) | жесты, взмах рукой, указание |
| Кисти | две формы — открытая ладонь и кулак с указкой (наконечник в фирменном оранжевом) |
| Бёдра (×2) | шаг при переходе между точками экрана |
| Планшет | появляется в руке в «деловых» сценах |

## Позы

`idle` (стоит), `wave` (машет — приветствие), `pointUp` (показывает указкой на потолок), `presentLeft` / `presentRight` (показывает указкой в сторону окна), `invite` (раскрытые ладони — «выбирайте»), `tablet` (с планшетом), `bye` (прощается).

Код: `src/components/anna/AnnaSvg.tsx` (рисунок), `poses.ts` (углы суставов), `Anna.tsx` (анимация), `script.ts` (реплики по сценам).
